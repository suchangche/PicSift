# PicSift

PicSift 是一款原生 macOS 图片筛选、查看与整理工具，专为 Apple Silicon Mac 设计。使用 SwiftUI 与 AppKit 构建，不依赖第三方框架。

## 功能特性

### 图片浏览与筛选

- 选择本地文件夹，读取当前目录下的图片，不递归扫描子文件夹。
- 默认筛选 JPEG，也可多选 RAW、HEIC、PNG、GIF、TIFF、WebP、BMP 等格式。
- 支持按日期多选筛选；优先使用 EXIF 拍摄日期，缺失时使用文件修改日期。
- 打开文件夹时先快速显示文件列表，再在后台补全拍摄日期。
- 异步缩略图、原图缓存和相邻图片预加载，减少浏览时的等待。

### 选择与查看

- 单击立即选择，再次点击已选图片可取消；支持 Command 多选、Shift 范围选择和 Command 全选。
- 双击在当前窗口查看大图，不创建独立图片窗口，也不强制切换全屏。
- 鼠标位置为中心缩放、触控板捏合缩放、放大后拖动及双指平移。
- 支持左右区域点击、方向键和底部缩略图栏切换图片。
- 底部缩略图始终将当前图片置于中央，越界位置留空，横竖图均按比例完整显示。
- 当前图预加载前后各两张，未命中缓存时先显示清晰预览，再替换为原图。

### 删除与撤回

- 支持单选、多选及全选删除，只影响当前筛选结果中的已选文件。
- 删除操作进入 macOS 废纸篓，不会直接永久抹除文件。
- 支持 Command+Z 按批次撤回删除，包括全屏查看时删除当前图片后的自动切换。
- 撤回记录仅保留在当前文件夹的本次运行中；切换文件夹或重启应用后不可撤回。

### 压缩与复制

- 将选中图片打包为 ZIP，默认保存到“下载”目录，也可自行指定。
- 将选中图片复制到独立目标文件夹，不修改原文件。
- 复制遇到同名文件时自动追加编号，例如 `名称-2.jpg`，不会覆盖现有文件。
- 压缩目录与复制目录分别持久保存，重启应用后仍会恢复。
- 完成后可选择在 Finder 中打开结果位置。

### macOS 原生体验

- 支持浅色与深色外观、半透明材质和克制的过渡动效。
- 可展开或收起筛选侧栏。
- 支持 Dock / Launchpad 重开主窗口。
- 仅提供 Apple Silicon（arm64）版本。

## 运行要求

- macOS 14 或更高版本。
- Apple Silicon Mac（M1、M2、M3、M4 或更新型号）。
- 构建时需要 Swift 6 工具链，可使用 Xcode 或 Command Line Tools for Swift。
- 系统自带 `/usr/bin/zip`，无需安装额外依赖。

## 构建与运行

在项目根目录执行：

```bash
swift build
./scripts/build-app.sh
open Products/PicSift.app
```

打包脚本会生成并临时签名以下应用：

```text
Products/PicSift.app
```

`Products` 和 `.build` 均为本地构建产物，不纳入版本控制。

## 使用说明

1. 点击“打开文件夹”并选择图片所在目录。默认显示 JPEG 图片，日期不限。
2. 在侧栏选择格式和日期。只选择一个分类时，另一个分类不限；同时选择时取交集。
3. 单击图片进行选择，Command 点击进行多选，Shift 点击进行范围选择；再次点击已选图片可取消。
4. 双击图片查看大图。使用左右区域、方向键或底部缩略图切换图片。
5. 使用滚轮或触控板捏合缩放，放大后可拖动或双指平移，按 Esc 返回图库。
6. 使用“复制所选”复制文件，使用“压缩所选”创建 ZIP。两个目标目录可在窗口底部分别设置。
7. 删除前会显示确认提示；本次运行中可按 Command+Z 撤回。

## 文件与隐私

- 图片扫描、解码、筛选、复制、压缩和删除均在本地完成。
- 应用不会上传图片，也不要求账户或网络服务。
- 只有用户明确选择的图片才会被复制、压缩或移到废纸篓，未筛选出的文件不受影响。
- 目标路径仅用于保存用户选择的输出位置，不会作为网络地址访问。

## 当前限制

- 目前仅支持 Apple Silicon macOS，尚未提供 Windows 版本。
- 只扫描所选文件夹的第一层，不扫描子文件夹。
- RAW 预览依赖 macOS ImageIO 对具体相机 RAW 格式的支持；不支持的文件会显示占位，不会修改原文件。
- 大图的首次解码速度仍取决于图片尺寸、相机格式和磁盘性能。

## 技术实现

- Swift 6、SwiftUI、AppKit
- ImageIO 图片解码与 EXIF 读取
- 两阶段文件夹扫描与后台日期补全
- 带内存上限的原图 LRU 缓存和相邻图片预加载
- macOS 废纸篓 API、系统 ZIP 工具和 UserDefaults 路径持久化
